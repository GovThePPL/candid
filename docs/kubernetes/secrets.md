# Kubernetes Environment Variable Reference

Complete reference for all environment variables used by Candid services. Organized into Secrets (sensitive) and ConfigMaps (non-sensitive).

## Secrets (use K8s Secrets)

These values are sensitive and must be stored in Kubernetes Secrets, never in ConfigMaps or plain manifests.

| Variable | Service | Description | Dev Default |
|----------|---------|-------------|-------------|
| `DATABASE_URL` | api, chat, worker | PostgreSQL connection string | `postgresql://user:postgres@db:5432/candid` |
| `REDIS_PASSWORD` | api, chat, redis | Redis auth password (embedded in `REDIS_URL`) | `candid-redis-dev` |
| `KEYCLOAK_BACKEND_CLIENT_SECRET` | api | OIDC client secret for API-to-Keycloak | `candid-backend-secret` |
| `KC_BOOTSTRAP_ADMIN_PASSWORD` | keycloak | Keycloak admin console password | `admin` |
| `KC_DB_PASSWORD` | keycloak | Keycloak database password | `postgres` |
| `POLIS_ADMIN_CLIENT_SECRET` | api | OIDC client secret for Polis admin operations | `polis-admin-secret` |
| `POLIS_ADMIN_PASSWORD` | api | Polis admin user password | `password` |
| `ANTHROPIC_API_KEY` | nlp | Claude API key (optional, for proposal drafting) | — |
| `OPENAI_API_KEY` | nlp | OpenAI API key (optional, alternative LLM) | — |
| `SECRET_KEY` | api | JWT signing key for pending social login tokens | `candid-dev-secret-key` |
| `TWILIO_ACCOUNT_SID` | api | Twilio Account SID (optional, for SMS verification) | — |
| `TWILIO_AUTH_TOKEN` | api | Twilio Auth Token (optional, for SMS verification) | — |
| `TWILIO_PHONE_NUMBER` | api | Twilio phone number in E.164 format (optional) | — |
| Polis JWT private key | polis-server | EC private key, file mount at `/app/keys/private.pem` | Generated by `dev.sh` |
| Polis JWT public key | polis-server | EC public key, file mount at `/app/keys/public.pem` | Generated by `dev.sh` |

## Issuer URL Consistency

`AUTH_ISSUER` (Polis), `KEYCLOAK_ISSUER_URL` (API), and `KC_HOSTNAME` (Keycloak) must all agree. The `iss` claim in Keycloak tokens is determined by `KC_HOSTNAME`. In dev this is `localhost`; in production set all three to your actual domain. See [Keycloak Production Setup](deployment-guide.md#keycloak-production-setup).

## Security Notes

- The API server's `config.py` includes a `_require_secret()` pattern that logs `CRITICAL` warnings if dev defaults are detected in production (`FLASK_ENV=production`)
- **Never** use the dev defaults (`postgres`, `admin`, `password`, `candid-backend-secret`, `polis-admin-secret`, `candid-redis-dev`) in production
- Generate strong random passwords: `openssl rand -base64 32`
- Generate Polis JWT keys: `openssl ecparam -genkey -name prime256v1 -noout -out private.pem && openssl ec -in private.pem -pubout -out public.pem`
